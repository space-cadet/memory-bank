# T27: Publish the Memory Bank CLI to npm

*Created: 2026-08-14*
*Last Updated: 2026-08-14*

**Status**: 🔄 **IN PROGRESS**
**Priority**: high
**Started**: 2026-08-14
**Dependencies**: T13 (Memory Bank CLI), T25 (Standalone Node Package)

## Objective

Prepare the `mb` command-line tool for a safe public npm prerelease, validate the exact artifact a user will install, and publish only after the documented release gates pass.

## Scope

- Package the CLI currently rooted at `mb-cli/` for npm distribution.
- Establish package identity, licensing, repository metadata, and user-facing installation documentation.
- Add repeatable release verification for a clean package install and essential CLI workflow.
- Publish and validate a prerelease only after the release gates are met and publication is explicitly authorized.

## Completion Criteria

### Package identity and artifact

- [x] Choose an available npm package name and public scope.
- [x] Add accurate `repository`, `bugs`, `homepage`, author, keywords, engines, and license metadata.
- [x] Add the repository license file and ensure all generated package metadata uses the same license and real public URLs.
- [x] Define a `files` allowlist or `.npmignore` so the tarball contains only runtime code, templates, and required documentation.
- [x] Exclude source backups, local databases, internal development snapshots, and other non-runtime artifacts from the tarball.

### Documentation and support contract

- [x] Write the npm package README with installation, upgrade, uninstall, and first-project instructions.
- [x] Update `docs/cli-workflow.md` to use npm installation rather than repository symlinks.
- [x] Document the optional SQLite/database dependency step and supported Node/package-manager versions.
- [x] State the supported product boundary: Markdown-first workflows are supported; cross-project parser/backfill work remains separate and experimental.

### Verification and automation

- [x] Add package-level automated tests for command parsing, template initialization, and tarball contents.
- [x] Add a clean tarball-install test: install the packed artifact into an empty temporary project, run `mb init`, and verify the generated Memory Bank structure.
- [x] Add a database workflow test: initialize the generated database, create a task/session, record work, regenerate, and validate the resulting files.
- [x] Add CI to run package tests, `npm pack --dry-run`, and the clean-install workflow before publication.
- [x] Verify the final tarball contents manually and record the evidence.

### Publication

- [x] Publish an npm prerelease (for example, `0.1.0-beta.1`) after explicit authorization.
- [x] Install the published prerelease into at least two representative projects and verify the documented workflow.
- [ ] Publish the first stable version only after prerelease feedback and the remaining release gates are resolved.

## Non-Goals

- Replacing the text-first Memory Bank workflow with database-primary storage.
- Completing the cross-project parser/backfill programme in T20/T21.
- Publishing the browser-first standalone server as part of this CLI package.
